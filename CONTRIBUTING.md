# Contributing

Thanks for your interest in TaskFlow AI. The project is an early prototype, so focused feedback and small, clearly explained improvements are especially helpful.

## Before you start

- Check the README and the documents in `docs/`.
- Open an issue to discuss larger changes before implementing them.
- Keep changes focused and avoid adding dependencies without a clear reason.

## Local setup

Requirements: Node.js 18 or newer.

1. Clone the repository.
2. Open `index.html` in a modern browser, or serve the folder with any simple static file server.
3. Run the tests with `npm test`.

## Pull requests

- Explain the problem and the proposed change.
- Include screenshots for visible interface changes when practical.
- Add or update tests for changed core behavior.
- Update documentation when product behavior or setup changes.
- Do not commit API keys, passwords, personal data, or generated secrets.

## Project status

This is a concept-stage prototype. Please avoid describing planned integrations or AI features as implemented until they actually exist.

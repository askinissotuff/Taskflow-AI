# User Guide

## Open the prototype

Open `index.html` in a modern browser. No account, API key, or build process is required.

## Add a task

1. Select **New task**.
2. Enter a task name.
3. Choose a project, priority, and optional due date.
4. Select **Create task**.

## Organize tasks

Use **My tasks** to view the task list. The tabs filter active and completed tasks. The search box searches task titles. Select the checkbox to mark a task complete, or use the × control to delete it.

## Create a project

Choose **New project**, enter a name and optional description, then create it. Projects display the number of tasks and a completion percentage based on completed tasks assigned to that project.

## Try the planning helper

Enter a goal in **Plan your focus** and select **Create a sample plan**. The current helper creates a fixed set of practical planning prompts. It does not call an AI model.

## Where your data lives

The prototype stores data in local storage in the browser you are using. It is not backed up or synchronized. Use the app for demo information only, not sensitive or confidential data.
